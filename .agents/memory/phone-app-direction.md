description: The user's reason for prioritizing dictation in the existing web app.

Dictation is important because the user eventually wants a phone-app version and wants users to dictate their scripts.

**Why:** the user explicitly stated this future product direction when requesting voice input.

**How to apply:** preserve a transcription interface reusable by a future mobile client. The current request adds dictation to the existing web app; it does not request building the native phone app yet.
