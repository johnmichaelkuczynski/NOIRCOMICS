---
name: Comic source fidelity
description: Why conceptual comic adaptations need faithful dialogue and a capable text model.
---

Keep central source propositions in the visible dialogue, using original wording where possible. Do not downgrade to a lightweight text model solely to save cost without checking demanding conceptual examples.

**Why:** a live adaptation with a lightweight model replaced a stated wish with a fear and omitted the source's central explanation, despite producing valid JSON and convincing noir images. Formatting and visual success do not establish semantic fidelity.

**How to apply:** use strict structured output and inspect dialogue against the source whenever changing the adaptation model or prompt. Scene descriptions do not compensate for claims missing from the dialogue.
